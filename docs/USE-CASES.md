## Manual acceptance workflow

`tests/live/capture-import.spec.js` (LIVE-02) additionally exercises real pasted-text resolution and the deployed photo-upload/OCR/review/save path using the shipped model and a generated clear title image. Permission timeout and invalid-image upload errors are covered in `scan-review.spec.js`.

Use the dedicated `keeper-e2e` profile, never the owner's `saint282` account. Open the CloudFront URL, sign in, search an exact printing, inspect its image and details, add a test quantity, return to the collection, refresh, reload, edit and delete. Try the scan screen, permission/fallback flow and a pasted import. End with an empty test collection and sign out. The separate `keeper-isolation` identity proves that another owner's row ID cannot be edited. No test invitation emails are sent.

Automated camera tests use a synthetic browser MediaStream to verify stability, duplicate suppression and track shutdown. The OCR test runs the actual shipped Tesseract engine/model against a generated clear card title. These prove different things: neither establishes real-world accuracy on sleeved/foil cards or a physical phone camera. A real phone on a desk, rear camera permissions, lighting/glare, and consecutive identical cards still need a hands-on hardware acceptance run. This limitation is visible rather than hidden behind mocked recognition.

## Coverage boundaries

Tests cover each visible control and its meaningful state transitions through representative inputs, not every possible value combination. External Scryfall links are checked for correct destinations rather than exercising Scryfall's own UI. Cognito's new-password screen is tested with a controlled challenge; no automated test changes the owner's password. Camera timeout, hardware-specific media errors, background tab lifecycle and every card layout are not exhaustively browser-tested. Missing/denied camera, OCR load error, unclear result, synthetic stream and real OCR are covered. Add new use cases and tests together when controls or adapters change.
