Try the scan screen, permission/fallback flow and a pasted import. End with an empty test collection and sign out. The separate `keeper-isolation` identity proves that another owner's row ID cannot be edited. No test invitation emails are sent.

Automated camera tests use a synthetic browser MediaStream to verify stability, duplicate suppression and track shutdown. A real phone on a desk, rear camera permissions, lighting/glare, and consecutive identical cards still need a hands-on hardware acceptance run. This limitation is visible rather than hidden behind mocked recognition.

Missing/denied camera, recognition load error, unclear result, synthetic stream and real recognition are covered. Add new use cases and tests together when controls or adapters change.
