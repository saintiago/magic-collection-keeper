# User categories

Categories describe the user's purpose, not fixed personas or access roles. One person can belong
to several categories. Experience ranges from curious beginner to expert within each category.

| ID       | Category            | Purpose                                                                        |
| -------- | ------------------- | ------------------------------------------------------------------------------ |
| USER-001 | Curious newcomer    | Explore Magic and understand cards they encounter.                             |
| USER-002 | Player              | Use cards to plan, build and improve decks, from casual to competitive play.   |
| USER-003 | Collector           | Keep an accurate collection, organize it and identify wanted cards.            |
| USER-004 | Trader or seller    | Use collection knowledge to decide what to exchange or sell.                   |
| USER-005 | Store operator      | Manage cards in the context of running a local game store.                     |
| USER-006 | Card reference user | Look up precise card information; includes judges and other experienced users. |

A judge may also be a player or collector; judging itself does not imply a separate app workflow.
Store operators share collection journeys, while their additional business workflows remain to be
defined. Audience priorities are not yet assigned.

[User journeys](user-journeys.md) identify the categories each journey serves.
